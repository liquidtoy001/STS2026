Before a run counts

  • Same eight IDs in the same order, and the batch tensor hash in manifest.json matches the baseline.
  • Same crop plan, seeds (2026 / 1234), 2,000-iteration budget, optimizer, precision and loss weights, except the change under test.
  • Fresh kernel, fresh model and optimizer; no resumed checkpoint.
  • status.json says completed. Failed or interrupted runs are kept but not entered as results.
  • Iterations, actual updates and AMP skips are reported. For GAN runs, report discriminator updates too.
  • Run in the same validated environment as the baseline, or re-run the baseline there first.
  • Listen to the exported target / mean / sample WAVs before writing conclusions.

Adding a result

  1. Open docs/site/assets/results.js and find the experiment's entry in STS.EXPERIMENTS.
  2. Copy the step-2000 values from evaluation/step_002000/summary.json for both modes. Do not round.
  3. Fill in iterations, updates, ampSkipped, params, seconds, evidence, and set status: "completed".
  4. Write the analysis in that experiment's team sections on this page and open a PR.

v2 · Adversarial training (GAN)

measured branch gan-group 07e663d · 2026-09-23 2026-09-29 · report

v0 and v1 train the decoder with regression losses only, and the Discriminator class is empty. The gan-group branch adds a waveform discriminator and least-squares GAN losses, and splits training into a discriminator step and a generator step.

GAN components developed by Mou and Warneke; completion commit 07e663d on 2026-09-23. GitHub branches: gan-group and Mou. Tag: gan-loss-completed, which currently points to the earlier 2026-09-22 commit 1f3fd0f, not the completion commit. Training of gan0 and gan1 was executed by tuirno.

What the branch contains

Discriminator

1-D conv stack on raw waveform, base_channels = 32: k15 s1 → k41 s4 ×4 (32→64→128→256→512) → k5 to 1 channel. LeakyReLU 0.2. Outputs a score per time position.

LSGAN losses

D: (D(x) − 1)² + D(G(z))². G: (D(G(z)) − 1)². Added to the reconstruction total with gan_weight = 1.0.

Two optimizers

Separate AdamW for generator and discriminator, both lr 1e-4, betas (0.8, 0.99). One shared GradScaler. Discriminator updates are counted by their own hook.

Update order

D step on real vs detached fake audio, then G step with D's parameters frozen so adversarial gradient reaches the decoder only.

Before comparing with v1

The branch sets MODEL_VARIANT = "original". Give GAN runs their own variant name so run folders are not confused with the baseline, and record both generator and discriminator update counts.

Merged version and the next runs

On 2026-09-24 benlu merged the GAN code with the v1 evaluation and removed DataParallel and autocast. The merged trainer was run by tuirno as a pair on Kaggle on 2026-09-29: 50,000 iterations each with gan_weight = 0 and 1, full objective (mel 1, STFT 0.5, wave 10, duration 1, KL 1). These results form their own comparison group and are not comparable with v1. Read the experiment report.
