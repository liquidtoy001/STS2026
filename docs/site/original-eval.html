Version v1 · baseline

Original model with shared evaluation

v1 keeps every model definition from v0 and adds a fixed, repeatable way to train and score it. Its measured run is the reference that all later changes are compared against. The GAN loss is still zero.

Frozen baseline c9f258c (PR #1) · 9fba268 (PR #2) tuirno · completed 2026-09-20 (Brisbane) RTX 4070 Ti SUPER open team sections

What changed from v0

  • sts_eval/reconstruction.py: ReconstructionEvaluator, metric functions, plot_history, provenance helpers.
  • Training batch fixed to LJ001-0001 … LJ001-0008 in that order, instead of the first shuffled batch.
  • Seeds fixed: training 2026, evaluation 1234. cuDNN deterministic, benchmark off.
  • Budget raised to 2,000 iterations. Evaluation at 0, 500, 1000, 1500, 2000.
  • Optimizer hook counts actual updates, separate from attempted iterations.
  • Per-run directory with run_config.json, status.json, training history, checkpoints and scored WAVs.
  • Local runner, report generator, subset downloader, Kaggle export, checkpoint rescoring.
  • 11 tests covering metrics, crop padding, RNG restoration, a real optimizer update and export.
  • The empty evaluate() stub and the clamped listening cell.

Evaluation protocol

The evaluator measures spectrogram → posterior encoder → decoder → waveform on the same eight utterances used for training.

Held fixed across every comparison

VariableValue
Samples and orderLJ001-0001 to LJ001-0008, batch of 8
Audio22,050 Hz, n_fft 1024, hop 256, win 1024
Cropdeterministic central 32 frames = 8,192 samples. Short utterances are padded for decoding; only real samples are scored. Crops under 1,025 valid samples fail loudly.
Seedstrain 2026, eval noise 1234; CPU/CUDA RNG state and module train flags are restored after evaluation
Budget2,000 training iterations, eval every 500, log every 50
OptimizerAdamW lr 1e-4, betas (0.8, 0.99), eps 1e-9, wd 0.01, clip 1.0
Loss weightsmel 10, STFT 1, wave 10, duration 0, KL 0
PrecisionAMP on, single GPU

Metrics

All metrics are computed per utterance and averaged arithmetically, with no padding in the reduction. Lower is better. They are errors, not accuracy percentages.

MetricDefinition
Log-mel L180 bands, magnitude mel, HTK scale, no normalization, natural log, floor 1e-5
STFT spectral convergence‖|S| − |Ŝ|‖F / ‖|S|‖F, averaged over the three resolutions
STFT log-magnitudeL1 of log magnitudes, floor 1e-7, same three resolutions

STFT resolutions (FFT, hop, window): (512, 128, 512), (1024, 256, 1024), (2048, 512, 2048); Hann, centered, reflect padding. These match the training loss, so the metrics overlap with the objective.

What this does and does not show

Reconstruction error on the training batch went down. This does not establish convergence, acceptable perceptual quality, or performance on unseen utterances. One seed was run, so training variation is unknown.

Reproducibility check

The final checkpoint was reloaded strictly in a fresh Python process after checking the data fingerprint and protocol, then rescored. Across 8 samples × 2 modes × 3 metrics, the largest per-sample absolute difference was 0. This confirms same-machine, same-environment rescoring only.

Running v1

Local GPU

python tools/prepare_ljspeech_subset.py
python tools/run_local_eval.py --data-dir data/LJSpeech-1.1 --steps 20 --eval-every 20      # smoke test
python tools/run_local_eval.py --data-dir data/LJSpeech-1.1 --steps 2000 --eval-every 500   # full baseline
python tools/report_local_eval.py output/local-eval/original_<UTC>

Rescore an existing checkpoint (no training)

python tools/run_local_eval.py --data-dir data/LJSpeech-1.1 \
  --checkpoint output/local-eval/original_<UTC>/checkpoints/vits_step_2000.pt

Kaggle

python tools/build_kaggle_eval.py   # writes output/kaggle/vits-light_v1_eval.ipynb

Upload the export, attach LJSpeech-1.1, enable a GPU and check DATA_DIR. Restart the kernel for every comparison run; resuming a checkpoint is rejected for comparison runs.

Integration contract for new models

Any v2+ model must expose the following so the same evaluator can score it. Add a thin adapter when needed, keeping these meanings.

model.posterior_encoder(spectrogram, spectrogram_lengths)
    # -> (z, mean, log_scale, mask); log_scale is log σ, not log variance
model.decoder(z_segment)          # [B, latent, 32] -> [B, 1, 8192]
model.hop_length                  # 256
model.segment_frames              # 32
model.segment_samples             # 8192

Build new components before the trainer, set MODEL_VARIANT, keep "original" selectable, and confirm batch hashes and crop plans match before comparing.
