Agent reply (simulated LLM stream)

The reply appears here word by word.

No language model runs: the reply is normalised and split into sentences first (as if the LLM wrote spoken-form text), then its words arrive one by one after the first-token delay at the set speed. Each strategy speaks it with real TTS calls as soon as it has the words it needs.

What the model produced

The mel spectrogram and the text-to-frame alignment of the current sentence appear here.

Mel spectrogram: 80 mel bands of the generated waveform, natural-log magnitude on a fixed scale shared by every model. Alignment: the hard monotonic path returned by model.infer(...)["attention"]; each character occupies the frames the duration predictor gave it. A and B share one time axis.
